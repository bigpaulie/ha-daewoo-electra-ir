# Security reporting

Do not post credentials, backups, `.storage` files or unredacted logs in a public issue. Review the [privacy policy](PRIVACY.md) before sharing diagnostics.

Use the [repository's](https://github.com/bigpaulie/ha-daewoo-electra-ir) private vulnerability-reporting option under **Security → Report a vulnerability**, if enabled by the maintainer. If no private reporting channel is available, first ask the maintainer to establish one without disclosing vulnerability details publicly. No private contact address is published in this source.

The integration should issue commands only through the configured Broadlink entity and must not modify existing integrations, invent sensor readings or resume reporting without the documented arming conditions. Report a bypass of these expectations with sanitized reproduction steps and affected versions.

This preview has no guaranteed response time or support lifecycle. Keep the physical remote available and use the last verified working control if unexpected behavior occurs.
